# 04 整行数据绑定

`Record` 使用 `Q_DECLARE_METATYPE`，每行仅在 `RecordRole` 保存一份结构体。设置 `setItemDataRole(RecordRole)` 后，context 版本的 bind 直接读取 `rowData.value<Record>()`。事件回调仍需查当前 index，再更新整份结构体；model 发出 dataChanged 后自动重绑。

## 阅读入口

- [example.cpp](example.cpp)：本例的所有 model、adapter、行控件和页面装配。
- [example.h](example.h)：只导出本例的 `createExample()`。
- UI 布局集中在 `setupUi()`，行为配置和连接集中在 `setupExample()`。

在统一程序中选择本项，或启动时使用 `list_capabilities --example 4`。

## 复制本例独立运行

只复制当前目录，增加以下 `main.cpp`，将它与本目录 `example.cpp` 一起编译；链接 VirtualItemViews 和 Qt Widgets，无需其他示例文件：

```cpp
#include "example.h"
#include <QApplication>
#include <QWidget>

int main(int argc, char **argv)
{
    QApplication app(argc, argv);
    QWidget *page = list_binding_context::createExample();
    page->resize(900, 640);
    page->show();
    const int result = app.exec();
    delete page;
    return result;
}
```
