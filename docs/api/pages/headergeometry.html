列宽 / 比例 / FitViewport / 隐藏换序

setColumnWidth · setColumnMinimumWidth · setColumnMaximumWidth · setColumnStretchFactor · setStretchLastColumn · setColumnResizeMode · setColumnHidden · moveColumn · setColumnResizeEnabled

默认 Independent。比例分配的是扣除固定列和间距后的剩余宽度，factor=0 保持自身宽度；此模式下拖动任意列或 setColumnWidth 会清除全部比例和末列拉伸，故先设固定宽度再设 stretch factors。FitViewport 根据当前比例让列宽总和适配视口，拖动边缘在相应侧按比例补偿；受最小/最大限制。拖动改宽默认关闭；模型列号、视觉顺序和隐藏状态不要混用。

实现：src/layout/headergeometry.cpp · src/widgets/virtualtableview.cpp · src/widgets/virtualheaderview.cpp

排序 / 过滤 / 布局保存恢复

setSortingEnabled · sortByColumn · setSortIndicator · saveHeaderState · restoreHeaderState

排序需要模型 sort 实现或 QSortFilterProxyModel；仅画 sort indicator 不等于数据已排序。saveHeaderState 保存列宽、顺序、隐藏、比例以及 pane/冻结配置；不保存业务数据或任意视图开关，ColumnResizeMode 是独立配置。restore 先验证再应用，检查 bool 返回值。树的展开状态与业务持久化需求单独处理，不要假定 header state 保存树展开。

ColumnGeometry

struct ColumnGeometry

HeaderGeometry 提供的列几何快照。逻辑序号标识模型列，视觉序号表示显示顺序；内容坐标和 viewport 坐标不可混用。

成员 / 取值 说明
int logicalIndex = -1; 模型逻辑列号，初始 -1 表示无效。
int visualIndex = -1; 视觉顺序中的列号，初始 -1。
qint64 contentX = 0; 内容坐标中的左边界，初始 0。
int viewportX = 0; viewport 坐标中的左边界，初始 0，随滚动变化。
int width = 0; 列宽，初始 0；隐藏列为 0。
bool hidden = false; 是否隐藏，初始 false。

struct ResizeSnapshot {
    QVector<int> sizes;
    quint32 orderRevision = 0;
    quint32 fitRevision = 0;
    qint64 extent = 0;
    int minimum = 0;
    int maximum = 0;
    QVector<int> spacings;
};

列边界按下时的尺寸快照，用于 resizeSectionFromEdge()。通过 resizeSnapshot() 获取，不要手工拼装；结构或可用长度变化会使快照失效。

成员 / 取值 说明
QVector<int> sizes; 按下时各逻辑 section 的尺寸，初始为空。
quint32 orderRevision = 0; 结构和顺序版本，用于失效检查，初始 0。
quint32 fitRevision = 0; 填充布局版本，用于失效检查，初始 0。
qint64 extent = 0; 捕获时可用总长度，初始 0。
int minimum = 0; 捕获时最小 section 尺寸，初始 0。
int maximum = 0; 捕获时最大 section 尺寸，初始 0。
QVector<int> spacings; 捕获时间距数据，初始为空。
