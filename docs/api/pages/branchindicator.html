默认圆角等边三角形 10 逻辑像素。只设置展开/收起其中一个图标时随展开动画旋转 90°；两个都设置时直接切换，自定义 renderer 自行处理。隐藏 branchArea 去掉自身 branch 格但保留祖先缩进；仅隐藏 indicators 保留占位。Tree 的 setIndentLeafItems(false) 可省略全叶子兄弟组占位，TreeTable 没有该开关。常规大小/颜色/对齐/padding 用便捷接口，只有完整自绘分支/连接线才实现 BranchIndicatorRenderer。

BranchIndicatorState

struct BranchIndicatorState

传给 branch 渲染器的单个缩进格状态。当前节点格负责展开箭头，祖先格可用于连接线；布尔值默认 false、深度默认 0。

成员 / 取值 说明
bool hasChildren = false; 该格对应节点是否有子节点。
bool hasSiblings = false; 该格对应节点下方是否还有同级节点。
bool adjoinsItem = false; 是否为当前行自身的 branch 格；只有此格承载展开箭头。
bool isExpanded = false; 对应节点是否展开；有子节点时才有展开含义。
int cellDepth = 0; 该格的绝对层级，0 为顶层，自身格等于 itemDepth。
int itemDepth = 0; 当前绘制行的深度，0 为顶层节点。
