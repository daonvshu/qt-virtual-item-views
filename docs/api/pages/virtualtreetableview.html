无需网络或服务器。所有内容默认可见；搜索只筛选当前页。完整继承 API 请沿基类链接查阅。

公开头文件：include/virtualitemviews/virtualtreetableview.h

组合表格列布局与树节点展开；支持冻结列，不支持冻结行。展开后的视图行号不是 QModelIndex::row()。

直接基类：VirtualTableView。

本页列出本类型声明的接口。模型、选择、编辑、拖放、背景、自动高度和诊断还需查 VirtualItemView。列、表头、pane、合并与排序查 VirtualTableView。“可继承”不代表所有布局都支持：请先看下方能力限制。

public 头文件 · L81 
    void setRowGridLineDepths(const QSet<int> &depths);

设置或读取需要显示分组边界的节点深度集合。显示根下的主节点深度为 0。空集合显示全部；负深度被忽略。边界按下一个可见节点的深度归属，内容末尾按 0 处理，因此 {0} 会在完整主节点子树结束后画线，不在主节点与第一个子节点之间画线。树表行号表头同步过滤；不影响列分割线、表头与内容的交界线或冻结分隔线。末尾是否绘制仍由末行自动隐藏开关控制。

默认值／初始状态：空 QSet<int>，显示所有深度的分割线。

组合用法

view 为 VirtualTreeView 或 VirtualTreeTableView；0/1 相对于当前 rootIndex。可在展开、收起或滚动后继续使用同一配置。

// Draw only boundaries between complete root groups.
view->setRowGridLineDepths(QSet<int>{0});
// Include first-level child boundaries as well.
view->setRowGridLineDepths(QSet<int>{0, 1});
// Restore all depths.
view->setRowGridLineDepths(QSet<int>{});
