能力与配套设置

Wrap 不等宽标签 / 自然尺寸 / 行对齐

setFixedItemHeight · setItemWidthRange · setItemWidth · setItemWidths · clearItemWidth · invalidateItemWidths · setItemSpacing · setRowSpacing · setLineAlignment

VirtualWrapView 宽度优先级：显式覆盖→SizeHintRole→adapter estimate→100px，再按范围/行宽裁剪；批量 setItemWidths 避免逐项重排。水平 itemSpacing 与垂直 rowSpacing 可分别设置，统一 item height；SelectRows 仍选择模型项，不会选整条显示行。WrapLayout 按真实子控件 sizeHint/约束排布，隐藏控件通常不占位；WrapWidget 接管控件所有权，takeWidget 交回调用者，clear 删除。

实现：src/widgets/virtualwrapview.cpp · src/layout/wrapitemlayout.cpp · src/layout/wraplayout.cpp · src/widgets/wrapwidget.cpp

组合用法

少量真实标签控件按行换行并限制容器高度。chips 为已加入父布局的 WrapWidget，需包含 WrapLayout 和 QLabel；addWidget() 接管标签所有权。内边距由 WrapLayout 设置，总高度上限包含容器装饰。

auto *layout = chips->wrapLayout();
layout->setFixedItemHeight(32);
layout->setItemSpacing(8);
layout->setRowSpacing(6);
layout->setContentsMargins(4, 4, 4, 4);
chips->setAutoHeightMaximumHeight(120);
chips->setAutoHeightEnabled(true);
chips->addWidget(new QLabel(QStringLiteral("Qt Widgets")));
chips->addWidget(new QLabel(QStringLiteral("C++")));
