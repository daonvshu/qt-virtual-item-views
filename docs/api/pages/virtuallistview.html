动态行高 / 测量 / 显式覆盖

setItemHeightMode · setUniformItemHeight · setEstimatedItemHeight · setAutoMeasureItemHeight · setRowSizePolicy · setRowHeight · clearRowHeight

Uniform 统一高度；Uniform 高度为 0 且开启测量时按首个物化项适配。Variable 使用估值并在物化后测量，不能为了 auto height 预创建全部项目。Table 的显式 setRowHeight 默认优先于测量，拖动行高也会形成显式值；恢复动态行为用 clearRowHeight。列宽变化会影响换行高度，选择合适 RowSizePolicy。Flow/Masonry/Wrap 使用各自专用尺寸 API，不可套用内核行高配置。

hover / selected 默认绘制和动画

visualState · setVisualStateBackgroundVisible · setHoverBackgroundColor · setSelectedBackgroundColor · setVisualStateAnimationDuration · setVisualStateAnimationEasingCurve

内置状态背景默认开启，动画默认 180ms OutCubic；业务控件保持透明并在 visualStateChanged 中更新按钮/复选框的显示即可。除非完全自定义外观，不要自己维护 hoveredIndex、动画或重画默认背景。原生拖动期间框架暂停普通 hover，结束后重新计算；不改变业务勾选数据。Flow/Masonry/Wrap 的状态圆角入口是 setStateBackgroundCornerRadius，List/Tree/Table 是 setVisualStateCornerRadius。

分割线深度过滤 / 整线四向边距

setGridLineMargins · gridLineMargins · setGridLineMarginReference · gridLineMarginReference · setRowGridLineDepths · rowGridLineDepths · setRowVisualStateMargins · rowVisualStateMargins

gridLineMarginReference 默认 Viewport，Content 使用完整内容端点，未滚到末尾不截短屏幕边缘。List/Tree/Table/TreeTable 的 setRowVisualStateMargins(left,right) 默认 0，仅调整行 hover/select 绘制，不改变命中；表格仅 SelectRows 生效，显示且开启状态背景的垂直表头与内容共享端点，边距只扣一次；隐藏或关闭表头状态时退回内容范围。gridLineMargins 默认全零，横线使用 left/right，竖线使用 top/bottom；计算完整线范围后应用，正数缩短、负数伸长，不是每个 cell 的 padding。表头与内容共享范围；外框、冻结分隔线和拖放指示器独立。树和树表的深度集合默认空（全部），{0} 只画完整主节点子树之后的边界，{0,1} 还画一级子节点边界。深度相对于显示根；负值忽略，末行自动隐藏仍生效。

    void setRowVisualStateMargins(int left, int right);

设置或读取整行 hover／选中背景的左右绘制边距，返回 QMargins 的上下值始终为 0。在原有状态形状计算后应用：正数缩短、负数延伸，最终受视图和行区域裁剪。只改变框架背景绘制，不改变控件几何、命中范围或选择；不受分割线边距参照开关影响。List／Tree 可与原有状态范围、状态 padding 和固定高度组合。Table／TreeTable 仅在 SelectRows 模式下生效。垂直表头显示且启用状态背景时，表头和内容合并为整行范围，边距只计算一次，圆角沿整体端点绘制；表头隐藏或关闭状态背景时从内容范围计算。不重复作用于每个 cell，水平表头及 SelectItems 模式不受影响。

默认值／初始状态：left = 0，right = 0。

组合用法

背景两侧各留出 12px，命中范围保持不变。

view->setRowVisualStateMargins(12, 12);

    QMargins rowVisualStateMargins() const;

设置或读取整行 hover／选中背景的左右绘制边距，返回 QMargins 的上下值始终为 0。在原有状态形状计算后应用：正数缩短、负数延伸，最终受视图和行区域裁剪。只改变框架背景绘制，不改变控件几何、命中范围或选择；不受分割线边距参照开关影响。List／Tree 可与原有状态范围、状态 padding 和固定高度组合。Table／TreeTable 仅在 SelectRows 模式下生效。垂直表头显示且启用状态背景时，表头和内容合并为整行范围，边距只计算一次，圆角沿整体端点绘制；表头隐藏或关闭状态背景时从内容范围计算。不重复作用于每个 cell，水平表头及 SelectItems 模式不受影响。

默认值／初始状态：left = 0，right = 0。

背景两侧各留出 12px，命中范围保持不变。

view->setRowVisualStateMargins(12, 12);
