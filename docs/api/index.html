先选布局，再组合框架能力

业务开始自绘、维护事件过滤器或缓存池之前，先按下方需求查找已有入口。每个视图页同时给出能力约束、配套设置、完整公开声明和可复制的独立章节。

VirtualItemView

共享内核（抽象基类）

模型、选择、滚动、复用、状态动画、编辑、拖放、背景边框和自动高度的共同入口。先查这里，再查具体视图。

VirtualListView

纵向列表

每个模型项一个 QWidget；支持可变行高、状态范围、冻结行和拖动让位。

VirtualTableView

多列表格

列宽、表头、冻结区域、合并和排序；可选择一行一个控件或一个单元格一个控件。

VirtualTreeView

单列树

真实节点展开动画、缩进、branch、层级拖放；不支持冻结行。

VirtualTreeTableView

多列树表

组合表格列布局与树节点展开；支持冻结列，不支持冻结行。展开后的视图行号不是 QModelIndex::row()。

VirtualFlowTableView

等宽响应式网格

模型行是项目；显示列由视口宽度决定。统一格高或宽高比，大量等尺寸卡片优先选择此视图。

VirtualMasonryView

独立高度瀑布流

按最短列排布，项目高度独立；适用于图片卡片。固定高度或统一比例且项目很多时优先考虑 Flow。

VirtualWrapView

不等宽换行

项目宽度独立、统一高度、按模型顺序换行；虚拟化显示，初始布局与宽度变化重排为 O(N)。

WrapWidget

少量真实控件的换行容器

直接 addWidget，不需要模型或 adapter，不复用。默认自动高度开启，配合最大高度内部滚动。

WrapLayout

可直接使用的换行布局

实现 heightForWidth、统一高度和行对齐；自身没有滚动条，限高滚动使用 WrapWidget。

VirtualHeaderView

可复用 section 控件的表头

表格默认表头。常规样式经 horizontalHeader()/verticalHeader() 配置，自定义内容换 HeaderWidgetAdapter。

常见组合与能力边界

需求 组合 / 边界
默认交互 ExtendedSelection + SelectRows；内置 hover/selected 开启；180ms OutCubic。改物化模式不会改选择范围。
输入或 Popup 优先 ItemEditorAdapter + edit()。不要默认增加 stack layout、全局焦点监听、每行常驻 editor。
整表高度 autoHeight 独立于 item height。用 setAutoHeightMaximumHeight 限高，0 表示完整内容，父布局不足由业务处理。
冻结 List/Table 可冻结行；Table/TreeTable 可冻结列；Tree/TreeTable 无冻结行。Flow/Masonry/Wrap 不提供行 pane。
尺寸 List/Tree/Table 用内核或表格行高；Flow/Masonry/Wrap 用专用尺寸 API，不能照抄 Variable+autoMeasure。
样式 外框、项底色、hover/select、间距、表头容器、section、corner 各有独立职责；透明业务控件才能露出框架底层状态。
少量标签 / 大量项目 少量真实控件用 WrapWidget/WrapLayout；模型复用用 VirtualWrapView；等宽网格用 Flow；不同高度最短列用 Masonry。

自适应高度 / 嵌套滚动 / 最大高度

setAutoHeightEnabled · setAutoHeightMaximumHeight

虚拟视图默认关闭，WrapWidget 默认开启。开启后内部 setFixedHeight，垂直 QSizePolicy::Fixed；上限 0 表示不限，不受父布局可用高度压缩。父容器放不下由业务安排外层滚动。开启时用 setAutoHeightMaximumHeight，不与 QWidget 的 setFixedHeight/setMaximumHeight 混用；关闭恢复原约束。高度包括内容、间距、适用半间距、表头和实际占位边框/横向滚动条；分割线不额外占高。没有内部滚动范围时滚轮交给外层，表头也同样处理。

这些公开基础类型服务于布局扩展和定位查询。正常业务接入通过具体视图和模型通知；不要同时手工操作 sizeIndex/resetItems 和模型结构来维护两份状态。ListLayout 持有 SizeIndex，内部行布局区分固定/动态尺寸；TreeVisibilityIndex 管理展开后的映射。此层没有“任意改内部布局后自动保持所有业务状态”的契约，扩展时逐项阅读源码。

实现：src/layout/listlayout.cpp · src/index/sizeindex.cpp · src/index/treevisibilityindex.cpp · src/core/scrollmapper.cpp

配套说明：docs/models.md
