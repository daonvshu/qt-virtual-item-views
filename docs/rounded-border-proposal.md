状态：待其他设备运行对比后确认。当前只在第 30 节示例中保留方案 2 和方案 3，默认选择方案 2，方案编号保持不变。当前观察认为两者具备可行性，跨设备的边缘质量、滚动表现和开销仍待确认；尚未确定框架默认行为或公开接口。

## 运行入口

构建现有 `table_capabilities` 目标后运行：

```sh
table_capabilities --example 30
```

源码位于 `examples/table_capabilities/30_borders/`，操作说明见 [第 30 节](../examples/table_capabilities/30_borders/README.md)。本页不依赖 SmoothScrollbar。两种方案使用相同模型、默认表头、QLabel 单元格和视图配置，切换时重新创建视图并选择首行。

## 候选方案

| 项目 | 方案 2：四角覆盖层 | 方案 3：整体 Alpha 合成 |
| --- | --- | --- |
| 实现位置 | `examples/table_capabilities/30_borders/cornercover.cpp`，覆盖绘制在 `borderdemo.cpp` | `examples/table_capabilities/30_borders/alphaframe.cpp` |
| 绘制方式 | 表格正常绘制，上层用固定纯色遮盖圆角外区域，再绘制边框 | `QGraphicsEffect` 获取整个视图及其子控件画面，用抗锯齿 Alpha 遮罩合成，再绘制边框 |
| 额外开销 | 主要为四角覆盖与边框绘制，不创建整表合成图 | 遮罩按尺寸、设备像素比及轮廓边界缓存；每次 effect 绘制仍获取源图并创建结果图、应用遮罩 |
| 背景适应 | 遮盖色必须与外部纯色背景一致；当前示例固定匹配纯色选项 | 透明区域可透出渐变、棋盘格等外部背景 |
| 保留的控件 | 默认表头、单元格、滚动条 | 默认表头、单元格、滚动条，统一参与合成 |
| 已知边界 | 渐变或棋盘格下出现纯色色块接缝是方案限制 | 大视图、高 DPI 和连续更新时的合成代价需要实测 |

按当前代码路径推断，方案 2 的额外成本更低；这不是测量结论，暂不提供帧率、耗时或提升比例。方案 3 的遮罩缓存不代表源画面或合成结果可以一直复用。

两种方案都不使用外轮廓的 `QWidget::setMask()`，视觉圆角仍保留矩形控件的命中范围。外框圆角、边框宽度与 hover／selected 圆角分别配置；边框内侧圆角使用 `max(0, 外框半径 - 边框宽度)`。

## 换设备后观察

在同一设备、同一 Qt 版本、相同构建配置和窗口尺寸下依次比较两种方案。性能对比优先使用 Release；不要把不同配置的结果直接比较。分别观察普通窗口和最大化窗口，在可用条件下覆盖 100%、125%、150%、200% 缩放及 Qt5、Qt6。仅记录系统版本、Qt 版本、构建配置、显示缩放和分辨率等必要条件，不记录用户名、设备名称、序列号或本地路径。

| 场景 | 操作 | 需要观察 |
| --- | --- | --- |
| 默认边框 | 纯色背景，半径 20、线宽 2 | 四角是否平滑，是否有白边、黑边、内容漏出或边框不均 |
| 参数变化 | 半径在 0、20、40 间切换，线宽在 0、1、2、8 间切换 | 直角与圆角切换、细边框和大圆角是否稳定，内外边缘是否对齐 |
| 透明背景 | 切换渐变与棋盘格 | 方案 3 是否真实透出背景；方案 2 的纯色接缝是否可接受 |
| 连续滚动 | 大数据量下滚轮滚动及双向拖动滚动条 | 卡顿、闪烁、残影、文字模糊、滚动条绘制和响应 |
| 状态动画 | 快速跨行移动鼠标、选择首行与末行、点击列头 | hover／selected 动画是否连续，圆角附近是否残留背景或穿帮 |
| 表头与间距 | 开关表头与行列间距 | corner、表头和间距是否越过外轮廓，边框是否被覆盖 |
| 冻结区域 | 开启冻结四边后双向滚动 | 冻结内容、分隔线和滚动区域在四角是否一致 |
| 小数据量 | 3 行 × 3 列，关闭强制滚动条 | 空白区域、滚动条出现或消失时的四角是否正常 |
| 尺寸与 DPI | 缩放窗口，条件允许时跨不同缩放的屏幕移动 | 遮罩尺寸和清晰度是否更新，是否出现旧轮廓或错位 |
| 圆角附近输入 | 点击与拖动靠近四角的滚动条和表头 | 遮盖后可操作区域是否符合预期，矩形命中范围是否可接受 |

若记录 CPU 或内存占用，应在相同场景下观察一段持续滚动与动画，并区分空闲和连续操作；示例当前不内置基准测试，单次主观感受不能作为量化结论。
