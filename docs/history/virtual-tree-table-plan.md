# VirtualTreeTableView 实施方案

状态：实施中，尚未完成逐项验收。本文记录目标和实施顺序；已有部分实现，不能据此认定所有功能可用。

## 目标与边界

新增独立的 `VirtualTreeTableView`，同时保留现有单列 `VirtualTreeView` 和平铺的 `VirtualTableView`。最终版本应具备 `VirtualTableView` 的全部表格能力，并增加 `VirtualTreeView` 的层级、展开及分支交互能力。各阶段可以只交付能力子集，但最终验收必须逐项对照现有两个视图；不能以“树表格暂不支持”结束某项表格功能。

新视图使用 `QAbstractItemModel` 的树形索引，不要求应用把树预先展平成表。纵向布局只处理展开后可见的节点，横向布局处理这些节点的列。业务控件继续按可见区域创建和复用。

## 核心契约

1. **节点与单元格身份**：每个节点以第 0 逻辑列的模型索引标识；同节点其他单元格从该索引取得同一父节点、同一模型行的对应列。展开状态、节点深度、行高覆盖、固定项和树拖放均绑定节点身份，不能绑定易变化的可见行号。列换序、隐藏或冻结后，分支图标仍跟随第 0 逻辑列；若该列隐藏，须明确定义可访问的展开入口（键盘和公开 API 仍可用）。
2. **列结构**：一套全局 `HeaderGeometry` 定义根索引下的逻辑列、视觉顺序和宽度。以 `model()->columnCount(rootIndex())` 确定列 schema；子节点所在父项缺少某列时，该位置为空白且不可编辑、选择或创建单元格控件，不伪造 `QModelIndex`。模型列插入、删除、移动时同步表头与可见单元格。第一阶段应以真实多列树模型验证 Qt 的父索引和 `siblingAtColumn()` 行为。
3. **可见行**：`TreeVisibilityIndex` 负责节点与可见行号之间的映射；`ListLayout` 负责可见行高度、间距、滚动及复用。展开、折叠、模型结构变化、排序和过滤后，保留有效的展开状态与滚动锚点，清理失效节点的状态。`setRootIndex()` 限定显示子树，并统一其列 schema 和深度计算。
4. **表头**：水平表头表示全局列；垂直表头表示当前可见行，默认行号随展开/折叠重新编号。垂直表头的行高调整绑定节点；从行号条拖动换序只允许同一父节点的兄弟项，并委托模型 `moveRows()`。跨父节点移动使用树拖放语义。模型拒绝移动时恢复预览。
5. **冻结与 pane**：左右冻结列、多个横向滚动组及 pane 分界线沿用表格的逻辑列语义。冻结首行和尾行按当前可见节点序列计算，展开/折叠后重新确定冻结节点；冻结行内的分支交互和列 pane 裁剪必须仍然有效。
6. **合并单元格**：沿用 `TableSpanProvider` 的模型索引锚点。列跨度遵守现有列 pane 边界；行跨度仅在同一父节点、模型顺序相邻且当前可见序列也连续时生效，不得跨父子边界、折叠边界或上下冻结 pane。条件不满足时按普通单元格显示，不绘制覆盖其他节点的合并区域；结构变化后重新计算。需确认提供者的反查不会把无效跨度误判为有效覆盖。
7. **排序与持久化**：表头排序交互调用模型或代理模型，视图不私自重排树。表头状态保存/恢复涵盖列顺序、宽度、隐藏、比例、冻结列与冻结行设置；展开状态如需跨进程恢复，应由应用提供稳定节点 ID 并单独持久化，不能序列化临时 `QModelIndex`。现有表格状态格式不可直接假定与新视图兼容。

## 复用方案

当前实现以 `VirtualTreeTableView : VirtualTableView` 为起点，让表格的公开 API、列布局、表头、pane 和控件物化继续共用一套实现；树视图提供可见节点到表格行的映射，并复用 `TreeVisibilityIndex` 和分支渲染器。这一路径只有在表格内部所有依赖平铺行号的操作都经映射扩展点处理后才成立。不能只覆写 `viewIndex()`：跨度便利 API、行高和固定项、模型结构通知、选择与焦点、可访问性、拖动行号条等路径都要逐一审计。

先以功能对照表定位平铺假设，再为确实依赖行来源的路径增加受保护的映射或语义钩子；不为新视图复制整套表格实现。每次修改共享代码都检查原表格行为。若某项表格能力无法通过有限扩展点正确复用，先抽取该部分为内部共享组件，再继续该阶段。公开 API 沿用继承得到的名称与参数语义，树特有设置另设接口；文档最终明确 adapter、header、span provider 在树模型中的约束。

## 功能对照台账

以下每行都是最终验收项。继承到一个 API 只表示接口存在，仍需验证它对可见树行、根索引和结构变化的语义。

| 来源 | 功能组 | 树表格必须达到的结果 |
| --- | --- | --- |
| 表格 | 两种物化模式 | 行控件与单元格控件均按可见行和可见列复用；不同父节点或列可绑定不同控件。 |
| 表格 | 行列几何 | 行高策略、显式行高、动态测量、列宽上下限、比例宽度、末列拉伸、横向 overscan、命中与滚动一致。 |
| 表格 | 表头 | 两轴默认与自定义表头、列拖动/隐藏/调整大小、行号条调整高度与合法行移动、排序指示及动画一致。 |
| 表格 | 冻结与 pane | 上下冻结行、左右冻结列、多滚动组及其表头、单元格、分支和分界线对齐。 |
| 表格 | 外观 | 行列间距及控件工厂、表头间距、横竖分割线的显隐/颜色/宽度/穿越选项、hover/selected 背景范围与动画一致。 |
| 表格 | 单元格行为 | 合并单元格、行/单元格选择、键盘定位、编辑焦点及 pin、拖放反馈、诊断计数一致。 |
| 表格 | 状态 | 列布局与冻结设置的保存恢复、排序后的映射、模型插删移/reset 后的状态清理正确。 |
| 树 | 层级 | 根索引、展开/折叠、可见行索引、节点深度、分支图标/自定义渲染、缩进及按深度行间距正确。 |
| 树 | 交互 | 分支点击、树式键盘导航、同父节点调整顺序、跨父节点拖放及三种分割线/背景覆盖范围正确。 |
| 两者 | 可访问性与规模 | 可见树节点同时具有层级与表格坐标；宽表深树仍只物化可见范围及 overscan。 |

## 分阶段实施

| 阶段 | 交付内容 | 完成标准 |
| --- | --- | --- |
| 0. 契约与基线 | 按上表建立 API/行为核查记录，确定节点列索引、根索引、缺失子列、模型通知与状态失效规则；审计表格内部平铺行号假设。 | 用多列、不同父节点列数及结构变更的模型证明索引契约；记录现有表格需要保持的行为和针对性验证目标。 |
| 1. 可见树行与基础列 | 新视图类、模型/根索引、展开/折叠、可见行虚拟化、纵向滚动、基础横向列布局、索引与几何命中。 | 不同深度的多列节点可正确显示和滚动；展开/折叠、插删移行、模型 reset 后索引和几何一致；不可见节点不物化。 |
| 2. 表头与列状态 | 水平/垂直表头、自定义 section、列宽调整、隐藏、拖动换序、排序指示、动画、比例宽度、末列拉伸、列状态保存恢复；垂直表头行高调整与同父节点行移动。 | 树列随第 0 逻辑列换序，所有表头与内容对齐；重启恢复列布局；行移动只影响合法兄弟项，模型拒绝时不留错误状态。 |
| 3. 两种物化模式 | `TableWidgetAdapter` 行控件模式及 `CellWidgetAdapter` 单元格模式、横向 overscan、固定/动态行高、行高策略、焦点/编辑器 pin 与回收。 | 宽表和深树仅创建可见及 overscan 控件；不同父节点可选不同控件；缺失列不绑定无效索引；滚动或折叠不误回收焦点控件。 |
| 4. 树交互与样式 | 分支图标及自定义渲染、缩进、鼠标与键盘展开、选择/定位、树节点深度间距；行/单元格 hover 和 selected 动画、自绘背景及范围选项。 | 分支命中在列换序、横向滚动、冻结列及行间距下正确；背景可选择仅内容、图标加内容或整行，且不错误覆盖分割线。 |
| 5. 完整表格布局 | 左右冻结列、多 pane 与独立滚动组、上下冻结行、行列间距与自定义间距控件、表头间距、横竖分割线和 pane 分界线的全部样式选项。 | 各 pane 中表头、单元格、分支图标和分割线对齐；展开/折叠后首尾冻结行按可见序列更新；零间距仍能分别显示横竖线。 |
| 6. 合并与拖放 | `TableSpanProvider`、跨度命中/绘制/物化、树拖放的前/后/放入节点、表格选择及拖放反馈。 | 非法跨父项/折叠边界/pane 跨度不会遮盖节点；拖放目标、指示线和模型提交与树语义一致；排序、过滤及结构变更后无残留跨度。 |
| 7. 完整性与交付 | 可访问性、诊断计数、公开 API 文档、最小多列树示例、与现有表格及树的逐项对照和性能回归。 | 两种 Qt 构建配置通过受影响目标的编译与相关非 GUI 测试；逐项对照表无未实现条目，现有表格/树行为未退化；文档说明新旧视图的选择和用法。 |

## 验收重点

- **功能对等**：逐项核对表格的表头、状态保存、列宽/比例、列换序、行高、两种控件模式、冻结行列、多 pane、间距、分割线、合并、选择/hover、编辑焦点、拖放及可访问性；核对树的根索引、展开状态、缩进/分支、树键盘导航、按深度样式及树拖放。每项记录新视图 API、验证方式和结果。
- **模型正确性**：覆盖不同深度与宽度、缺失子列、代理模型排序/过滤、节点移动和模型 reset；验证选中、展开、滚动锚点及跨度不会错误地转移到相同行号的另一节点。
- **规模与兼容**：延续现有可见区域物化与 `TreeVisibilityIndex` 的复杂度约束；宽表、深树和频繁展开时记录控件数、模型查询数及布局耗时。共享组件改动要同时验证原 `VirtualTableView` 和 `VirtualTreeView`。

测试依各阶段受影响行为选择最小相关目标；GUI 交互和截图检查按项目验证政策及明确的测试授权执行。方案文档本身只做静态检查。

当前工作区已经包含新类、示例、文档和部分共享代码改动。阶段顺序是剩余实施和验收的依赖顺序，不代表前面阶段已经通过；在所有对照项有明确结果之前，不能宣布最终目标完成。
