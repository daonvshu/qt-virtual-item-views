# VirtualTreeTableView 验收记录

状态：进行中。此文件记录实施方案中的逐项证据，不代表 GUI 行为已经验收。

## 验收口径

- 表格能力以 `VirtualTableView` 当前公开 API 和行为为基线，树能力以 `VirtualTreeView` 为基线。继承 API 或示例编译通过，只证明接口接通，不证明交互和绘制正确。
- 用户已明确允许针对树表格新增并运行 Qt GUI/offscreen 测试；相关条目只有在对应验证通过后才标记通过。
- 最终结论必须同时检查 Qt5 与 Qt6、原表格与原树的共享代码回归，以及宽表深树的物化数量和布局成本。

## 功能台账

| --- | --- | --- |
| 节点身份与根索引 | `VirtualTreeTableView::viewIndex()` 使用可见节点与同级列；`viewItemForIndex()` 排除根 schema 之外的子列；切换根或模型结构变化后，清除不在可见行或超出根列 schema 的当前项及导航锚点；`TreeVisibilityIndex::handleModelChanged()` 清理失去列 0 层级身份的状态，列结构变化时清理相关选择与当前项，并在列 0 改动前撤销受影响子树的固定项。非零列单元格固定项仅在其所属节点身份有效时保留。`tst_treetablemodelcontracts` 覆盖不同父节点列数、根深度、代理排序与列 0 替换。 | 模型插删移、reset 后选择、当前项、固定项、滚动锚点和根视图的组合行为。 |
| 展开与可见行 | `TreeVisibilityIndex` 提供可见行映射；普通展开和折叠在 `ListLayout` 中增量插删可见区间，保留未变化行的测量高度与深度间距，新插入行才计算深度间距。垂直表头以稀疏间距覆盖记录例外行，普通展开/折叠只更新覆盖项和新行；固定行高不变时，插入无需重建所有间距 extent。递归展开和模型结构变化仍重建布局。跨父节点移动后再展开新父节点时，已展开后代的分支块会在同次遍历中重建；纯模型用例验证后代可见行反查。展开/折叠通知在刷新后检查模型与根代次及持久节点状态，不向业务发出已失效节点的通知。 | 大树频繁展开时的布局耗时、控件数与滚动稳定性；深度间距覆盖几乎所有可见行时，稀疏项更新仍是线性成本；布局回调同步切换模型或根时的完整物化路径仍需核验。 |

## 静态核查

- `CMakeLists.txt` 将新头文件和实现加入 `VirtualItemViews`，`install(DIRECTORY include/virtualitemviews ...)` 将公开头文件纳入安装包；`examples/CMakeLists.txt` 登记 `tree_table_view`，README 链接独立的最小用法文档。
- `VirtualItemView` 的结构变更与 reset 处理在 `managesVisibleRows()` 为真时不提前重建布局；树表格自己的模型通知随后更新 `TreeVisibilityIndex` 并刷新可见行。
- 行控件模式下 `TableRowLayoutContext::column(0)` 同时移动起点并缩小宽度；`ColumnHost` 使用该几何避开分支装饰区域。实际裁剪和绘制仍待 GUI 验收。
- 合并行跨度的末端可见行距离判定由 `siblingSpanContinuityTracksExpandedDescendants` 覆盖展开与折叠情形。

- Qt5 与 Qt6：`tree_table_view` 编译通过。
- Qt5 与 Qt6：`tst_headergeometry` 通过，覆盖稀疏间距的大行数位置与间隙命中。
- Qt5 与 Qt6：`tst_treetablemodelcontracts`、`tst_treevisibilityindex` 相关纯模型测试通过，包含列 0 祖先换列和跨父节点移动后重新展开的用例。
- `git diff --check` 无空白错误。
- 只读深查发现的极大跨度行号溢出、极大缩进溢出、合并行分支命中、拖放指示线逐后代扫描、空选择的可访问性列查询，以及替换选择模型后的无障碍通知重连，已在代码中修正；Qt5 与 Qt6 的 `tree_table_view` 均重新编译通过。
- 分支渲染器的同指针重复设置现在可将所有权升级为视图托管；新旧树视图采用相同契约。Qt5 与 Qt6 的 `tree_table_view`、`tree_view` 均编译通过。
- 模型切换增加代次校验：`selectionModelChanged` 或控件回收回调中嵌套切换模型时，外层不再为被取代的模型连接表格/树信号或覆盖其表头状态；此项仍需最终 Qt5/Qt6 编译和行为核验。
- `TreeVisibilityIndex` 拒绝外部模型索引作为根或递归展开起点，避免对当前模型传入外来父索引；纯模型契约用例覆盖拒绝行为与正常递归展开。
- `TreeVisibilityIndex` 的根、普通展开和递归展开入口拒绝非第 0 列层级索引；纯模型用例覆盖非零列自身挂有子项时仍不会污染可见行和展开集合。
- 行与单元格整体回收先脱离活动容器，再调用 adapter 的 `unbind`；同步嵌套模型切换不会让回收迭代器失效，也不会在外层返回时清掉新模型刚物化的控件。此项需最终 Qt5/Qt6 编译与交互核验。
- 模型删除行/列的范围回收也先更新活动集合和索引查找表，再对移出的控件调用 `unbind`；回调中的同步模型切换不再破坏范围回收的迭代器或重新覆盖新模型集合。
- 根索引切换使用持久节点身份和根切换代次；回收回调若同步改变模型或根，较早的调用不再覆盖新根，目标节点在回调中失效时也不会继续应用。
- 模型请求由 `QPointer` 跟踪：控件回收或 `selectionModelChanged` 的同步槽若销毁目标模型，后续安装、信号连接与表头标签只使用仍存活的当前模型。
- 表头排序提交在同步通知后重新核对模型身份；槽中替换或销毁模型时，不会对旧对象继续调用 `sort()`。
- `VirtualTableView::setModel()` 在表头 adapter 重绑和列/行表头几何更新的同步回调后检查模型切换代次；外层调用不再继续覆盖回调里安装的新模型状态。此项尚缺交互验证。
- 树表格结构变更和 reset 的跨度提供者、表头几何及选择回调之后检查模型与根代次；旧列变更通知不再恢复新模型的选择快照。共享物化循环在 adapter `bind`/`unbind` 中同步切换模型或根的完整重入安全性仍未证明。
